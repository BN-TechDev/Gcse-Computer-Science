# GCSE Computer Science

A collection of Python programs and exercises completed during my GCSE Computer Science course.

## Repository structure

- `01-basic-python/` - beginner Python exercises and input/output practice
  - `multiplication_table.py` - prints a multiplication table for a number from 1 to 12
- `02-lists-and-averages/` - working with lists, totals and averages
  - `student_average.py` - calculates totals and averages for 3 students

## Notes

This repository has been organised into folders by topic so it is easier to find and understand each task.

The original files are still kept in the repo root for reference, but the organised versions are shown above.
