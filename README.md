# GCSE Computer Science

This repository is a collection of Python programs and exercises created as part of a GCSE Computer Science course. It includes small coding tasks focused on everyday programming concepts such as calculations, decision-making, loops, and data handling.

## Repository overview

The project is organised into a folder named `Computer Science GCSE`, which contains the individual exercises and programs completed during study.

## Current contents

- `Computer Science GCSE/Code for timetables`
- `Computer Science GCSE/Code for working out the average score of 3 students`

These examples demonstrate practical Python problem solving and are useful for revision, learning, and improving coding confidence.

## Purpose

This repository is intended to:

- document code written during GCSE Computer Science study
- provide examples of simple Python solutions
- support revision and practice of programming fundamentals
- serve as a learning record for future projects

## Requirements

To run the scripts, you will need:

- Python 3 installed on your computer
- a text editor or IDE such as VS Code, PyCharm, or IDLE

## How to run a script

1. Open a terminal or command prompt.
2. Navigate to the folder containing the Python file.
3. Run the script with:

```bash
python filename.py
```

Replace `filename.py` with the actual Python file name you want to run.
